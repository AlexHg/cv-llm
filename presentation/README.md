# Presentación cv-llm

Deck [reveal.js](https://revealjs.com) con el sistema visual de Concil.ia y paleta Banorte.

## Cómo verla

```bash
pnpm start
```

Abre [http://localhost:5173](http://localhost:5173).

También puedes abrir `index.html` en el navegador (carga reveal.js desde CDN).

## Navegación

| Tecla | Acción |
| --- | --- |
| `→` `espacio` | Siguiente |
| `←` | Anterior |
| `F` | Pantalla completa |
| `Esc` | Vista general |

Imprimir o exportar a PDF: añade `?print-pdf` a la URL.
